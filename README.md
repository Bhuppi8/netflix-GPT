# 🎬 Netflix GPT

A feature-rich Netflix clone enhanced with **AI-powered movie recommendations** using OpenAI and TMDB APIs. Built with **React**, **Vite**, **TailwindCSS**, and **Redux Toolkit**.

---

## 🚀 Features

### 🔐 Authentication (Firebase)

- **Login / Sign Up Forms**: Secure validation using the `useRef` hook.
- **Auto-Redirection**: Smart routing that redirects unauthenticated users to the Login page and logged-in users to the Browse page.
- **Profile Sync**: Automatically updates the user's display name and profile picture upon registration.

### 📺 Browse Page (The Netflix Experience)

- **Hero Section (Main Container)**: Features a cinematic, auto-playing, muted YouTube trailer running in the background with title overlays.
- **Movie Rows (Secondary Container)**: Organised, responsive scrollable lists (_Now Playing_, _Popular_, etc.) utilizing the TMDB Image CDN.
- **Performance Optimisation**: Custom hooks implemented with **Memoization** to prevent redundant API calls.

### 🤖 GPT Search Page

- **AI Movie Suggestions**: Leverage the OpenAI API to search for movies using natural language queries.
- **TMDB Integration**: Converts text recommendations from GPT into visual movie result cards.
- **Multi-Language Support**: Fully dynamic language selector for a global user experience.

### 📱 Core Enhancements

- **Global State**: Managed via Redux Store (`userSlice`, `movieSlice`, `gptSlice`).
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Secure Environment**: Kept keys safe using `.env` variables (properly hidden via `.gitignore`).

## 🛠️ Project Setup

### 1. Clone & Install

```bash
git clone <your-repository-url>
cd netflix-gpt
npm install
```

### 2. Environment Variables Configuration

Before starting the application, create a `.env` file in the root directory and populate it with your API keys:

```ini
VITE_TMDB_KEY=your_tmdb_api_key_here
VITE_OPENAI_KEY=your_openai_api_key_here
```

### 3. Run the Development Server

```bash
# Using standard Vite environment
npm run dev

# Alternatively, using node native watch if configured
node --watch src/app.js
```

## 📁 System Architecture & Components

- **Main Container**: Handles the background trailer video and main movie metadata.
- **Secondary Container**: Dynamically lists movies generated by custom hooks (`usePopularMovies`, `useNowPlayingMovies`).
- **GPT Search Bar & Suggestions**: Container mapping and reusing the `MovieList` component to render dynamic AI recommendations.
